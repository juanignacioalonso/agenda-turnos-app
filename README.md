# 📅 Sistema de Gestión de Turnos y Notificaciones

Aplicación web para la gestión de citas y turnos profesionales, con integración de notificaciones automáticas vía WhatsApp.

## 🚀 Tecnologías

Este proyecto utiliza una arquitectura desacoplada (Headless):

* **Backend:** Django 5 + Django REST Framework (Python).
* **Frontend:** Angular 17+ (TypeScript).
* **Base de Datos:** PostgreSQL (Desarrollo en SQLite).
* **Integraciones:** WhatsApp Business API / Twilio (Próximamente).

## 📋 Prerrequisitos

Asegúrate de tener instalado:
* Python 3.10+
* Node.js v18+ y npm
* Angular CLI (`npm install -g @angular/cli`)
